# 📋 TaskBuddy – Task Management Application

## 📌 About The Project

**TaskBuddy** is a user-friendly Task Management Application built using **React.js**. It helps users organize and manage their daily tasks efficiently.

The application allows users to add new tasks, update existing tasks, delete completed or unwanted tasks, and track their task completion progress.

It also provides a Progress Tracker to visually represent the status of tasks and helps users stay organized, productive, and focused on their daily goals.

## ✨ Features

### 1. ➕ Add Tasks
- Users can easily add new tasks to their task list.
- Enter task details and click the **Add Task** button.
- Newly added tasks are displayed in the task list.

### 2. ✏️ Update Tasks
- Users can edit the details of existing tasks.
- Select a task to update its information.
- Changes can be made easily without creating a new task.

### 3. 🗑️ Delete Tasks
- Users can remove unwanted tasks from the list.
- Click the delete (trash) icon to delete a particular task.
- Helps keep the task list clean and organized.

### 4. 🧹 Clear All Tasks
- Users can clear all tasks with a single click.
- The Clear All Tasks button removes all tasks from the list.
- Saves time when users want to start with a fresh task list.

### 5. 📊 Progress Tracker
- Provides a visual representation of task completion status.
- Helps users monitor their progress.
- Makes it easier to understand how many tasks are completed and how many are remaining.

## 🚀 How To Use

Follow these simple steps to use TaskBuddy:

**Step 1: Adding Tasks**
- Enter the task details in the input field.
- Click the "Add Task" button to add a new task.

**Step 2: Updating Tasks**
- Click on the task you want to edit.
- Update the task details as required.

**Step 3: Deleting Tasks**
- Click the trash icon next to a task to delete it.

**Step 4: Clearing All Tasks**
- Click the "Clear All Tasks" button to remove all tasks at once.

**Step 5: Tracking Progress**
- View the Progress Tracker to check your task completion status.
